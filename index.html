Watching gradient descent

A 337-parameter network, written without any ML library, trained, then projected onto the 2D plane where it moved the most.

See the landscape ↓
01

Data

Two interleaved half-moons, 400 noisy points. No straight line separates them, so the model needs hidden layers to bend the decision boundary.

02

Forward pass

2 → 16 → 16 → 1. Tanh in the hidden layers, sigmoid at the output, binary cross-entropy as the loss. Every weight lives in one flat vector θ.

h1 = tanh(X·W1 + b1)
h2 = tanh(h1·W2 + b2)
p  = σ(h2·W3 + b3)
L  = −mean( y·log p + (1−y)·log(1−p) )
03

Backpropagation

The chain rule, applied layer by layer from the loss back to the input. Sigmoid + cross-entropy simplify to p − y. The analytic gradient is checked against finite differences before training.

dz  = (p − y) / n
dW3 = h2ᵀ·dz
dh2 = dz·W3ᵀ ⊙ (1 − h2²)
…   same pattern down to W1
04

Gradient descent

Full batch, θ ← θ − η∇L, for 1500 steps. A snapshot of θ is saved every 10 steps: that sequence is the path.

05

Projecting 337 dimensions to 2

PCA on the snapshots (θₜ − θ*) gives the two directions δ₁, δ₂ where the optimizer moved the most. The loss is then evaluated on a 41×41 grid: L(θ* + αδ₁ + βδ₂).

06

Reading the result

A steep first drop, then a slow slide along a flat valley toward the minimum. It is a slice: real curvature in the other 335 dimensions stays hidden.
